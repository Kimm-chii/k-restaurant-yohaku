# SORA 空 — Japanese Dining & Culinary Space

Exploring modern web experiences through thoughtful design, responsive interfaces, and slow-simmered Japanese culinary storytelling.

## ✦ Core Focus

- **Interface Design**: Minimalist aesthetics inspired by Japanese Yohaku (余白), focusing on balance, clarity, warm-neutral tone palettes, and intentional space.
- **Frontend Implementation**: Designing and implementing responsive interfaces with modern frontend tools, centered around single-source data architecture (`siteContent.ts`) for effortless client maintenance.
- **Creative Exploration**: Interactive menu category filtering, responsive floating mobile action widgets, smooth transitions, and visual storytelling reflecting authentic 16-hour broth and handcrafted cuisine.

## 🛠️ Development Process

This project was developed through an AI-assisted creative workflow, using AI as a tool for faster prototyping, exploration, and refinement.

AI supports the workflow, but the creative direction, design decisions, and final experience are guided by human intent.

My primary focus and contributions include:

- **Defining UI & Visual Direction**: Conceptualizing a warm neutral aesthetic (`#F9F7F2`), high-contrast dark accents, and refined serif/mono typographic hierarchy.
- **Interface Design Decisions**: Structuring a single-view layout prioritizing the dining menu, guest reviews, direct directions, and operational details.
- **Customizing & Refining Components**: Tailoring modular components (Header, Hero, Compact About, Menu, Reviews, Contact, Footer) and adding a floating mobile category navigator.
- **Implementing Frontend Interactions**: Building instant dietary filter chips (Gluten-Free, Vegan, Vegetarian), smooth scroll triggers, and overlay drawers.
- **Optimizing Responsive Experiences**: Auditing mobile touch targets, viewport scaling, and fluid layouts for flawless browsing across all screen sizes.
- **Testing, Refining & Deploying**: Verifying production builds, optimizing performance, and ensuring zero broken handlers or missing assets.
